# Khaadi-Inspired E-Commerce Landing Page

Premium Pakistani fashion e-commerce landing page inspired by **Khaadi.com**.

## Features

- **Hero Carousel** — Full-width auto-playing (4s) with fade transitions, pause on hover, arrow + dot navigation, slide-up text animation
- **4 Product Collections** — Bridal, Daily Wear, Summer, Kids — all authentic Pakistani outfits
- **Banner Sections** — Themed gradient banners for each collection with CTA
- **Animations** — Scroll-triggered fade-in, smooth hover effects, button ripple, carousel text reveal
- **Responsive** — Desktop (4-col) → Tablet (2-col) → Mobile (1-col)
- **Mobile Menu** — Hamburger toggle with slide-down nav
- **Back to Top** — Floating button appears on scroll
